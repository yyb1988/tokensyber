隐私与服务条款

数据存储

TokenSyber 的所有游戏数据（进度、金币、库存、展示柜、市场记录等）均存储在您的浏览器 localStorage 中，不会上传至任何服务器。

  • 清除浏览器缓存将永久丢失所有游戏进度
  • 不同浏览器或设备之间的数据互不相通

插件数据收集

TokenSyber Claude Code 插件仅读取 Claude Code 会话 transcript 中的 token 使用量（input_tokens + output_tokens 数字），用于驱动游戏内的 3D 打印进度。插件不会读取、上传或存储您的对话内容。

  • 读取内容：仅 usage.input_tokens 和 usage.output_tokens 字段
  • 传输方式：本地 WebSocket（127.0.0.1），数据不离开您的设备
  • 存储位置：仅 ~/.tokensyber/state.json（token 计数）

网络连接

游戏页面通过 WebSocket 连接至本机运行的 TokenSyber 服务器（端口 3001-3010）。所有通信均在 localhost 内完成，不经过外部网络。

第三方服务

游戏页面从 CDN 加载以下第三方资源：

  • Three.js（3D 渲染库）— 来自 CDN
  • 3D 模型文件 — 来自对象存储服务

上述请求遵循各服务的隐私政策，本游戏不控制也不收集这些请求产生的数据。

Cookie 与追踪

TokenSyber 不使用 Cookie、不使用任何用户追踪或分析工具（如 Google Analytics）。

免责声明

TokenSyber 是一个免费的实验性项目，按"原样"提供，不提供任何担保。

  • 游戏数据可能因浏览器更新、存储限制等原因丢失
  • 游戏机制（金币价值、模型库存等）可能随时调整
  • 项目可能随时停止维护
